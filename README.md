# Food Store - Интернет-магазин продуктов питания

## 🚀 Технологии

- **Frontend:** Next.js 14, React, TypeScript, Tailwind CSS
- **Backend:** Nest.js, TypeScript, PostgreSQL, TypeORM
- **Инфраструктура:** Docker, GitHub Actions

## 📁 Структура проекта
food-store-project/
├── frontend/ # Next.js приложение
├── backend/ # Nest.js API
├── database/ # Миграции и схемы БД
├── docs/ # Документация
└── scripts/ # Вспомогательные скрипты

## 🛠 Установка и запуск

## Frontend
cd frontend
npm install
npm run dev

## Backend
cd backend  
npm install
npm run start:dev
